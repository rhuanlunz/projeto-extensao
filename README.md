# Projeto de Extensão - Gerenciador de Disponibilidade de Recursos

O Gerenciador de Disponibilidade de Recursos é uma aplicação web desenvolvida como parte do Projeto de Extensão da disciplina de Desenvolvimento Back-End da UNESC.

O sistema tem como objetivo centralizar e facilitar o gerenciamento dos recursos físicos do Bloco B da instituição, permitindo que alunos, professores e administradores consultem a disponibilidade dos recursos, acompanhem seu status e realizem solicitações de forma simples e organizada.

Além de atender uma necessidade real da comunidade acadêmica, o projeto proporciona aos alunos a aplicação prática de conceitos relacionados ao desenvolvimento web, banco de dados, engenharia de software, metodologias ágeis e trabalho colaborativo.

## Objetivos do Projeto

* Centralizar o gerenciamento dos recursos físicos do Bloco B.
* Facilitar a consulta de disponibilidade dos recursos.
* Melhorar a organização dos recursos por categorias e localização.
* Permitir o envio de solicitações relacionadas aos recursos cadastrados.
* Proporcionar uma experiência intuitiva para os usuários da comunidade acadêmica.
* Aplicar boas práticas de desenvolvimento de software em um projeto real.

## Metodologia de Desenvolvimento

O projeto foi desenvolvido de forma colaborativa, utilizando princípios de metodologias ágeis para promover organização, adaptação contínua e evolução incremental das funcionalidades.

### Práticas Utilizadas

* Planejamento e divisão das atividades em entregas incrementais.
* Desenvolvimento iterativo com validações frequentes.
* Controle de versão utilizando Git e GitHub.
* Utilização de Pull Requests para revisão e integração de código.
* Gerenciamento de branches para desenvolvimento isolado de funcionalidades.
* Documentação contínua das alterações realizadas.
* Colaboração constante entre os integrantes da equipe.

## Boas Práticas de Engenharia de Software

Durante o desenvolvimento foram adotadas práticas voltadas à qualidade, manutenção e evolução do sistema:

* Separação entre Front-End e Back-End.
* Organização modular da aplicação.
* Padronização de nomenclaturas e convenções de código.
* Controle de acesso baseado em perfis de usuário.
* Validação de dados no Front-End e Back-End.
* Estruturação do código visando legibilidade e manutenção.
* Documentação técnica do projeto e de sua evolução.
* Utilização de versionamento para rastreabilidade das alterações.

## Utilização de Inteligência Artificial

Ferramentas de Inteligência Artificial foram utilizadas como apoio ao desenvolvimento do projeto, auxiliando em atividades como:

* Refinamento de requisitos.
* Pesquisa e validação de soluções técnicas.
