# Projeto Extensão - Gerenciador de Disponibilidade de Recursos

O Gerenciador de Disponibilidade de Recursos é uma aplicação web desenvolvida como parte do Projeto de Extensão da disciplina de Desenvolvimento Back-End da UNESC.

O objetivo do sistema é centralizar e otimizar o gerenciamento dos recursos físicos do Bloco B da instituição, permitindo que alunos, professores e administradores consultem, reservem e administrem recursos de forma organizada, transparente e eficiente.

## Objetivos do Projeto

- Facilitar o controle de disponibilidade dos recursos.
- Reduzir conflitos de agendamento.
- Melhorar a comunicação entre usuários e administradores.
- Proporcionar uma experiência simples e intuitiva para a comunidade acadêmica.

## Metodologia de Desenvolvimento

O projeto foi desenvolvido seguindo princípios de metodologias ágeis, com foco em entregas incrementais e melhoria contínua.

### Práticas Utilizadas

- Planejamento e divisão das tarefas em etapas menores.
- Desenvolvimento incremental com validações frequentes.
- Controle de versões utilizando Git e GitHub.
- Utilização de Pull Requests para revisão e integração de código.
- Gerenciamento de branches para isolamento de funcionalidades.
- Realização de testes contínuos durante o desenvolvimento.
- Documentação das funcionalidades e processos do sistema.

## Boas Práticas de Engenharia de Software

Durante o desenvolvimento foram adotadas diversas boas práticas visando qualidade, manutenção e escalabilidade do sistema:

- Separação de responsabilidades entre Front-End e Back-End.
- Estruturação do código seguindo padrões do framework utilizado.
- Padronização de nomenclaturas e convenções de código.
- Uso de versionamento semântico nas alterações.
- Organização modular para facilitar futuras expansões.
- Tratamento de erros e validações de dados.

- Utilização de ambientes de desenvolvimento controlados.
